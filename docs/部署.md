# 部署 Kept（开源版）

Kept 是一个单独运行的程序：网页端已经编译进二进制，数据库是 SQLite（也可以用 Postgres），全文索引是本地文件。有两种部署方式，功能完全相同：

- **Docker**（第一节）：一个容器加一个数据卷，OCR 等工具已经装在镜像里。
- **二进制**（第二节）：直接在 Linux 或 macOS 上运行一个程序文件，用 systemd 管理；OCR 等工具由系统的包管理器安装。

两种方式的数据目录格式相同，可以互相迁移：用 `kept backup` 备份，再在另一种方式下 `kept restore`（见第八节）。下文的命令以 Docker 为例（`docker exec kept kept …`），二进制部署时换成 `sudo keptctl …`。

## 一、Docker 部署

### 构建镜像

在仓库根目录执行：

```bash
docker build -f deploy/Dockerfile -t kept:v1.13.9 \
  --build-arg VERSION=v1.13.9 \
  --build-arg COMMIT=$(git rev-parse --short HEAD) .
```

### 运行

```bash
docker run -d --name kept --restart unless-stopped \
  -p 8000:8000 -v kept-data:/data \
  -e TZ=Asia/Shanghai \
  kept:v1.13.9
```

打开 `http://服务器地址:8000`，第一次访问会进入初始化页面，创建实例管理员。没有界面时也可以用命令行：

```bash
docker exec -it kept kept user create --admin --email admin@example.com admin
```

命令会提示输入密码；在脚本里使用时，可以用环境变量 `KEPT_PASSWORD` 传入密码（`kept user set-password` 同样适用）。

其他账号由管理员在"设置 → 账号管理"中创建（不开放自助注册）。

也可以用 docker compose：

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

### 停止与重启

```bash
docker stop -t 40 kept
```

服务收到停止信号后会等进行中的任务完成（最多 `KEPT_SHUTDOWN_TIMEOUT`，默认 30 秒），未完成的任务不会丢失，重启后自动重新排队。

## 二、二进制部署

### 下载

从 [GitHub Releases](https://github.com/joy12825/kept/releases) 下载对应系统的包，每个包旁有 SHA256 校验文件：

| 文件 | 系统 |
|---|---|
| `kept-<版本>-linux-amd64.tar.gz` | Linux x86-64（多数服务器、NAS 的虚拟机） |
| `kept-<版本>-linux-arm64.tar.gz` | Linux ARM64（树莓派 4/5、ARM 服务器） |
| `kept-<版本>-darwin-arm64.tar.gz` | macOS Apple 芯片 |
| `kept-<版本>-darwin-amd64.tar.gz` | macOS Intel |

程序是静态编译的，不依赖系统的 C 库。Linux 包里有 `kept`、`install.sh`、`kept.service`、`kept.env`（配置示例）和说明；macOS 包里有 `kept`、`kept.env` 和说明。

### 依赖

处理 PDF 与识别扫描件要用到几个命令行工具（Docker 镜像里已经装好）：

| 用途 | 命令 | Debian / Ubuntu | Fedora / RHEL | macOS（Homebrew） |
|---|---|---|---|---|
| 读取文字、生成缩略图 | pdfinfo、pdftotext、pdftoppm | `poppler-utils poppler-data` | `poppler-utils poppler-data` | `poppler` |
| 扫描件文字识别 | ocrmypdf、tesseract | `ocrmypdf tesseract-ocr tesseract-ocr-chi-sim tesseract-ocr-eng tesseract-ocr-osd` | `ocrmypdf tesseract tesseract-langpack-chi_sim tesseract-osd` | `ocrmypdf tesseract-lang` |
| OCR 的依赖 | gs、qpdf | `ghostscript qpdf` | `ghostscript qpdf` | 随 ocrmypdf 安装 |
| iPhone 照片 HEIC（可选） | heif-dec | `libheif-examples libheif-plugin-libde265` | `libheif-tools` | `libheif` |

装好后运行 `kept doctor`：逐项列出工具、OCR 语言包、数据目录是否可写，缺少必需项时退出码为 1。HEIC 解码工具是可选的，没有时只是不收 HEIC 照片。

### Linux 安装（systemd）

```bash
tar xzf kept-<版本>-linux-amd64.tar.gz && cd kept-<版本>-linux-amd64
sudo ./install.sh --with-deps
```

`--with-deps` 用 apt 安装上表的依赖（Debian/Ubuntu）；其他发行版先自己装好依赖，再运行 `sudo ./install.sh`。安装脚本：

- 创建不能登录的系统用户 `kept`；
- 程序装到 `/usr/local/bin/kept`，另装 `/usr/local/bin/keptctl`（以服务的身份和配置运行 kept 的命令）；
- 配置写到 `/etc/kept/kept.env`（已存在时不覆盖），数据目录是 `/var/lib/kept`；
- 安装 systemd 服务 `kept`，并运行一次 `keptctl doctor`。

按需修改 `/etc/kept/kept.env`（格式是每行 `变量=值`，配置项见第三节），然后启动：

```bash
sudo systemctl enable --now kept
```

打开 `http://服务器地址:8000` 进入初始化页面，或用命令行：`sudo keptctl user create --admin --email admin@example.com admin`。

日常操作：

| 做什么 | 命令 |
|---|---|
| 状态、日志 | `systemctl status kept`，`journalctl -u kept -f` |
| 改配置后生效 | `sudo systemctl restart kept` |
| 停止 | `sudo systemctl stop kept`（会等进行中的任务，最多 40 秒） |
| 备份、检查等 | `sudo keptctl backup /mnt/nas/kept-backups`、`sudo keptctl check` …… |

### 升级

下载新版本的发布包，解压后运行 `sudo ./install.sh`：替换程序并重启服务，配置和数据不动，数据库迁移在启动时自动执行。升级前建议先备份（`sudo keptctl backup …`）。

### macOS

适合在 Mac 上自用或试用：

```bash
brew install ocrmypdf tesseract-lang poppler libheif
tar xzf kept-<版本>-darwin-arm64.tar.gz && cd kept-<版本>-darwin-arm64
xattr -d com.apple.quarantine kept   # 解除下载隔离
export KEPT_DATA_DIR=~/kept-data
./kept doctor
./kept serve
```

要开机自动运行，可以写一个 launchd 的 LaunchAgent，或者用 Docker Desktop 按第一节部署。

### 从源码构建

需要 Go 1.23+、pnpm 9+：

```bash
cd server && make release
```

产物在项目根目录的 `dist/`，包含四个平台的压缩包和 SHA256 校验文件。构建会先生成网页端再编译服务端，首次运行时间较长。

## 三、配置

全部配置都通过环境变量设置，启动时一次性检查，有错误会全部列出并退出。镜像里已经设置了 `KEPT_DATA_DIR=/data`、`KEPT_HTTP_ADDR=:8000` 和 `TZ=Asia/Shanghai`；二进制部署时这些写在 `/etc/kept/kept.env` 里（默认数据目录 `/var/lib/kept`）。

| 变量 | 默认 | 说明 |
|---|---|---|
| `KEPT_DATA_DIR` | `/data`（镜像中） | 数据目录 |
| `KEPT_DATABASE_URL` | 空（数据目录里的 SQLite） | 把数据库放在 Postgres，例如 `postgres://kept:密码@db:5432/kept`，见第七节 |
| `KEPT_HTTP_ADDR` | `:8000` | 监听地址。改了端口时，镜像自带的健康检查（固定访问 8000）需要一起调整 |
| `KEPT_LOG_LEVEL` | `info` | `debug` / `info` / `warn` / `error` |
| `KEPT_LOG_FORMAT` | `text` | `text` / `json` |
| `KEPT_WORKERS` | CPU 核数的一半，最多 8 | 后台任务并发数；OCR 很耗 CPU，小机器上可以设为 1 或 2 |
| `KEPT_SHUTDOWN_TIMEOUT` | `30s` | 停止时等待进行中任务的最长时间 |
| `KEPT_SESSION_TTL` | `720h` | 登录会话闲置多久后失效 |
| `KEPT_TRUSTED_PROXIES` | 空 | 反向代理的地址（IP 或 CIDR，逗号分隔），见第六节 |
| `KEPT_SECURE_COOKIE` | `auto` | `auto`：通过 HTTPS 访问时给 Cookie 加 Secure；`always` / `never` |
| `KEPT_AUDIT_RETENTION` | `8760h` | 活动记录保留多久 |
| `KEPT_MAX_UPLOAD_SIZE` | `200MB` | 单个上传文件的上限 |
| `KEPT_OCR_LANGUAGES` | `chi_sim+eng` | OCR 语言（镜像中已装中文简体和英文语言包） |
| `KEPT_OCR_MODE` | `skip` | `skip`：只识别没有文字的页面；`redo` / `force` |
| `KEPT_OCR_ROTATE` | `true` | 识别前把横着、倒着的页转正（需要 tesseract 的 `osd` 数据） |
| `KEPT_OCR_DESKEW` | `true` | 识别前纠正歪斜的扫描页（`redo` 模式下不纠偏） |
| `KEPT_OCR_ROTATE_THRESHOLD` | `5` | 方向判断要多有把握才转正（0–100） |
| `KEPT_SEARCH_LIMIT` | `10000` | 一次关键词搜索最多召回的文档数 |
| `KEPT_GOTENBERG_URL` | 空 | Office 文档转换服务的地址，见第四节 |
| `KEPT_CONSUME_DIR` | 空 | 监听目录，见第五节 |
| `KEPT_BARCODES` | `false` | 识别 PDF 中的分隔条码与 ASN 条码，见第五节 |
| `KEPT_BARCODE_DPI` | `300` | 识别条码时的分辨率（72–600） |
| `KEPT_BACKUP_DIR` | 空 | 每日自动备份的目录，见第八节；也可以在"设置 → 实例管理 → 文件安全"里选（v1.13.9） |
| `KEPT_EXPORT_DIR` | 空 | 每天 03:15 把各空间导出为普通文件夹的目录（v1.6.5），见第八节 |
| `KEPT_SMTP_HOST` 等 | 空 | 发信（通过邮件发送文档），见第九节 |
| `KEPT_BOOK_SOURCES` 等 | `openlibrary,googlebooks` | 按 ISBN 查找书目的数据源，见第十节 |
| `KEPT_PUBLIC_URLS` | 空 | 手机 App 连接用的服务器地址，逗号分隔，例如 `http://192.168.1.10:8000,https://docs.example.com` |
| `TZ` | `Asia/Shanghai`（镜像中） | 决定每日计划项的时刻 |

## 四、Office 文档（可选）

Word、Excel、PowerPoint、OpenDocument 和 RTF 文件要转换成 PDF，才能在网页上预览、查找高亮和下载可搜索版。转换由 [Gotenberg](https://gotenberg.dev) 完成：

```bash
docker network create kept
docker run -d --name gotenberg --network kept --restart unless-stopped gotenberg/gotenberg:8
docker run -d --name kept --network kept ... -e KEPT_GOTENBERG_URL=http://gotenberg:3000 kept:v1.13.9
```

用 docker compose 时加上 `--profile office`，并在 `kept` 服务里设置 `KEPT_GOTENBERG_URL: http://gotenberg:3000`。

没有配置时也照常收下：docx、xlsx、pptx 等文件里的文字会读出来，可以搜索；旧的 doc/xls/ppt 读不出文字。这些文档记为"待转换"，配好 Gotenberg 后服务器会自动补上转换。

## 五、监听目录（扫描仪直接存到 NAS）

把一个目录挂进容器并设置 `KEPT_CONSUME_DIR`，放进去的文件会自动入库：

```bash
docker run -d --name kept -p 8000:8000 -v kept-data:/data -v /mnt/nas/scans:/consume \
  -e KEPT_CONSUME_DIR=/consume kept:v1.13.9
```

服务会在目录里为每个空间建一个文件夹，名称是"空间 ID-空间名称"（如 `2-王家`）。

```
/consume/
  2-王家/
    电费.pdf             → 王家的待整理
    发票/专票/a.pdf      → 同时加上标签"发票""专票"
    双面/                → 单面扫描仪的双面合并，见下文
  _未能入库/             不能入库的文件，旁边的 .原因.txt 写明原因
```

- 文件写完（连续两次扫描大小不变，并且已经过了 5 秒）才会入库，入库后原文件删除。每 10 秒扫描一次。
- **双面扫描**：先扫所有正面存到 `双面/`，再扫反面存到同一个文件夹；两个 PDF 页数相同时，按"正 1、反 1、正 2、反 2……"顺序合并。
- **条码**（`KEPT_BARCODES=true`）：带分隔条码的页把一次扫描拆成几份；`ASN` 开头的条码自动填入原件编号。
- **同一路径作为新版本**（v1.7.13，默认关闭）：在监听目录设置里打开后，按原路径再次放入的文件作为上次那份文档的新版本。
- 目录需要能被容器里的用户（uid 1000）读写。

## 六、反向代理与 HTTPS

建议在前面放反向代理（Caddy、Nginx 等）提供 HTTPS。注意：

- **保留原始的 Host 头**：服务端检查 Origin 与 Host 是否一致，代理改写 Host 会导致所有修改操作被拒绝。
- **传递 `X-Forwarded-Proto`**，让 Cookie 带上 Secure 标记。
- **设置 `KEPT_TRUSTED_PROXIES` 为代理的地址**，例如 Docker 网络里用 `172.16.0.0/12`，同一台机器上用 `127.0.0.1`。
- 上传大小限制和超时要放宽（Nginx：`client_max_body_size 200m;`）；实时进度用 SSE，需要关闭缓冲（Nginx：`proxy_buffering off;`）。

Caddy 示例：

```
docs.example.com {
    reverse_proxy kept:8000
}
```

## 七、数据库放在 Postgres（可选）

默认数据库是数据目录里的 SQLite，家庭和小团队用它就够了。已经有 Postgres 服务或希望统一备份时，可以改用 Postgres（v1.13.3）：

```bash
docker run -d --name kept -p 8000:8000 -v kept-data:/data \
  -e KEPT_DATABASE_URL='postgres://kept:密码@db.example.com:5432/kept' kept:v1.13.9
```

用 Docker Compose 时：

```yaml
services:
  db:
    image: pgvector/pgvector:pg17
    environment: { POSTGRES_USER: kept, POSTGRES_PASSWORD: 密码, POSTGRES_DB: kept }
    volumes: [kept-db:/var/lib/postgresql/data]
  kept:
    image: kept
    depends_on: [db]
    ports: ["8000:8000"]
    volumes: [kept-data:/data]
    environment: { KEPT_DATABASE_URL: "postgres://kept:密码@db:5432/kept?sslmode=disable" }
volumes: { kept-db: {}, kept-data: {} }
```

- **需要的扩展**：`citext`（Postgres 自带）和 `vector`（[pgvector](https://github.com/pgvector/pgvector)）。第一次启动时收好会创建它们，数据库用户没有权限时请先手动执行 `CREATE EXTENSION citext; CREATE EXTENSION vector;`。
- **数据目录照样需要**：原件、缩略图、全文索引仍然在数据目录里，只有数据库换了位置。
- 连接地址里的密码不会出现在日志里。

## 八、数据目录与备份

```
/data
├── app.db          数据库
├── media/          原件、归档件、缩略图
├── index/          全文索引（可以重建：删除后启动，会在后台重新建立）
├── branding/       实例的 Logo
├── backups/        升级前的自动备份（保留最近 3 份）
└── tmp/            处理中的临时文件
```

### 备份

设置 `KEPT_BACKUP_DIR`，服务启动后先备份一次，之后每天 02:30 自动备份：

```bash
docker run -d --name kept -p 8000:8000 \
  -v kept-data:/data -v /mnt/nas/kept-backups:/backups \
  -e KEPT_BACKUP_DIR=/backups kept:v1.13.9
```

也可以只把目录挂进容器，到"设置 → 实例管理 → 文件安全 → 存到另一块硬盘"里填容器路径（v1.13.9）。

随时手动备份：

```bash
docker exec kept kept backup /backups
```

备份目录里有数据库快照（保留最近 7 份）和它引用的原件、缩略图。再次备份时只复制新增或变化的文件。建议放在另一块磁盘或 NAS 上，并定期复制到异地。

### 恢复

恢复到一个**空的**数据卷（服务不能在运行）：

```bash
docker run --rm -v kept-data-new:/data -v /mnt/nas/kept-backups:/backups kept restore /backups
docker run -d --name kept -p 8000:8000 -v kept-data-new:/data kept:v1.13.9
```

### 导出为普通文件

```bash
docker exec kept kept export --workspace 王家 /backups/王家-导出
```

导出的目录里，每个抽屉一个文件夹，按年份分开，文件名是"日期 标题"；`清单.csv` 列出每份文档的类型、往来方、标签和备注。也可以在网页的"设置 → 存储 → 导出整个空间"下载 zip。

### 定时导出（v1.6.5）

设置 `KEPT_EXPORT_DIR` 后，每天 03:15 把每个空间导出到以空间名命名的文件夹：按抽屉和年份分文件夹、带清单，不装 Kept 也能翻看。

## 九、发信（可选）

配置 SMTP 邮件服务器后，成员可以把文档作为附件通过邮件发出，也可以开启邮件提醒（每天 08:00 汇总发送）。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `KEPT_SMTP_HOST` | 空 | 邮件服务器；为空时不发信 |
| `KEPT_SMTP_PORT` | `587` | 端口；`465` 时加密默认 `tls` |
| `KEPT_SMTP_SECURITY` | `starttls` | `starttls` / `tls` / `none` |
| `KEPT_SMTP_USERNAME`、`KEPT_SMTP_PASSWORD` | 空 | 登录用户名和密码（很多邮箱要用"授权码"） |
| `KEPT_SMTP_FROM` | — | 发件人，必填，如 `Kept <kept@example.com>` |
| `KEPT_SMTP_MAX_ATTACHMENTS` | `20MB` | 一封邮件附件的总大小上限 |

配置后在"设置 → 系统状态 → 发信"中发一封测试邮件。

## 十、书目查找（可选）

书目对话框里输入 ISBN 后可以从 Open Library 和 Google Books 取回书目信息。服务器需要能访问外网，或者设置 `HTTPS_PROXY`。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `KEPT_BOOK_SOURCES` | `openlibrary,googlebooks` | 数据源；`none` 关闭在线查找 |
| `KEPT_GOOGLE_BOOKS_KEY` | 空 | Google Books 的 API 密钥 |
| `KEPT_BOOK_LOOKUP_URL` | 空 | 自己的书目接口，地址中的 `{isbn}` 换成 13 位 ISBN |

## 十一、从 Paperless-ngx 迁移

1. 在 Paperless 中导出：`docker compose exec webserver document_exporter ../export`（得到含 `manifest.json` 的目录）。
2. 把导出目录挂进收好的容器，导入到某个空间：

```bash
docker exec kept kept import paperless --workspace 王家 /import/export
```

往来方、类型、标签、自定义字段、文档和备注都会导入；不重新识别文字。可以放心重复执行。

## 十二、运维

- **健康检查**：`GET /healthz` 检查数据库、全文索引和磁盘剩余空间，镜像的 `HEALTHCHECK` 每 30 秒调用一次。
- **排查**：每个请求有一个编号（响应头 `X-Request-ID`），由这个请求排进的后台任务日志里也带同一个编号。
- **系统状态**（实例管理员，"设置 → 系统状态"）：版本、运行时长、各部分大小与剩余空间、索引状态、外部工具是否可用。
- **日志**：输出到标准输出，用 `docker logs kept` 查看；"设置 → 日志"中可以按级别和关键字查看最近 2000 条。
- **忘记管理员密码**：

```bash
docker exec -it kept kept user set-password admin
```

- **连接手机**：在"设置 → 连接手机"中用 App 扫码。需要在外网使用时，设置 `KEPT_PUBLIC_URLS` 加上外网的 HTTPS 地址。
- **丢失两步验证的手机**：`docker exec kept kept user disable-2fa <用户名或邮箱>`。

## 十三、手机 App

iOS App 与服务器同版本发布，通过网页端"设置 → 连接手机"的二维码连接。App 免费，按服务器版本显示功能。

- 局域网使用时，`KEPT_PUBLIC_URLS` 填上服务器的局域网地址；在外面也要用时，再加上反向代理的 HTTPS 地址，App 会按顺序尝试。
- 自签证书的 HTTPS：二维码里带着证书指纹，App 只信任这个证书。
- 一台手机可以连接多个空间，每个空间扫一次码。

开源版（本仓库）即免费版，不含收费与企业版模块：

| | 免费版（本仓库） |
|---|---|
| 成员 | 最多 6 人 |
| 共享空间 | 1 个 |
| 功能 | 收、理、找、提醒，书房，两步验证，备份与导出，Postgres，单份文档的分享链接 |

`kept license status` 和"设置 → 版本与授权"页会写明是开源构建，不支持导入许可证。

要使用收费功能（AI、外部存储、家人隐私文档、工作流等），换用[官方发布的镜像或安装包](https://github.com/joy12825/kept/releases)，数据目录可以直接沿用，换好后导入许可证即可。许可证购买：[https://kept.djycode.com](https://kept.djycode.com)。
